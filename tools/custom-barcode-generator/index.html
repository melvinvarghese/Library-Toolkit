What is the custom barcode generator?

Use a custom barcode generator when your library already has its own accession numbers, member IDs, shelf identifiers or other values. Enter one value per line, choose a barcode format, and generate a preview without sending the list to a server.

Features

  • Enter multiple custom values, one per line, with a maximum of 500 values per batch.
  • Choose from Code 128, Code 39, EAN-13, EAN-8, UPC, UPC-E, ITF-14, ITF, MSI, Codabar and Pharmacode.
  • Adjust bar colour, background colour, barcode height, module width and columns.
  • Print or save the generated sheet as PDF, and download the first barcode as SVG or PNG.

How to use the custom barcode generator

  1. Open the Custom Barcode Generator.
  2. Enter one identifier on each line. Keep each value exactly as it should be encoded.
  3. Select a barcode format that is compatible with the values and your scanner.
  4. Adjust the bar and background colours, barcode height, module width and number of columns.
  5. Select Generate, review the preview, then print or download the available artwork.

Common library uses

This tool is designed for practical library workflows, including:

  • Encoding library accession numbers or local item IDs.
  • Making barcodes for equipment, files or other library property.
  • Creating a small custom batch when values do not follow a consecutive sequence.

Frequently asked questions

Can I encode letters as well as numbers?

Yes, formats such as Code 128 and Code 39 can encode supported letters and numbers. Other formats have stricter character and length rules.

Which formats are available?

The selector includes Code 128, Code 39, EAN-13, EAN-8, UPC, UPC-E, ITF-14, ITF, MSI, Codabar and Pharmacode. Not every format accepts every kind of value.

Can I change the barcode colours?

Yes. You can choose the bar colour and background colour, and adjust the barcode height and module width.

Can I download an individual barcode?

The tool provides SVG and PNG download options for the first generated barcode, as well as printing the sheet or saving it as PDF.

Is there a batch limit?

You can enter up to 500 values in one batch.
