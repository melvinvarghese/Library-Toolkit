What is the barcode sheet designer?

A barcode sheet designer helps you control how a batch of library barcodes fits on paper. Enter values one per line, choose a barcode format, and adjust the page dimensions and spacing to suit your label stock or printer.

Features

  • Enter custom barcode values one per line.
  • Choose Code 128, Code 39, EAN-13, EAN-8 or UPC.
  • Set the number of columns, barcode height and module width.
  • Customize paper width and height, page margins and the gap between labels.
  • Preview the sheet before printing or saving it as a PDF.

How to use the barcode sheet designer

  1. Open the Barcode Sheet Designer and enter one barcode value per line.
  2. Choose a barcode format that supports the values you entered.
  3. Set the number of columns and barcode height and module width.
  4. Enter the paper width and height in millimetres, then adjust the page margin and gap.
  5. Generate the preview and check that the layout fits your paper. Print a test sheet before using label stock.

Common library uses

This tool is designed for practical library workflows, including:

  • Fitting barcode labels to custom-sized paper or label sheets.
  • Adjusting margins and spacing to match a library's printer setup.
  • Creating a consistent multi-column sheet from a manually entered list.

Frequently asked questions

Can I use paper sizes other than A4?

Yes. You can enter a custom page width and height in millimetres within the tool's supported range.

How many columns can I use?

The column setting supports between one and six columns.

Can I change the space between labels?

Yes. Adjust the page margin and gap settings to control the layout.

Which barcode formats are supported?

The selector offers Code 128, Code 39, EAN-13, EAN-8 and UPC.

Can I save the sheet as a PDF?

Yes. Use the print action in your browser and select Save as PDF.
