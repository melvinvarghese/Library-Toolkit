Create sequential barcodes for your library

Use this free continuous barcode generator to create a printable sequence for library books, accession numbers, membership records and other items that need unique identification numbers. Enter the first and last number, choose a barcode format and arrange the results on an A4 sheet.

How to use the barcode generator

  1. Enter the starting and ending numbers for your sequence.
  2. Keep the same number of digits in both values if you need leading zeros, such as 000001 to 000050.
  3. Choose Code 128 or Code 39 and set the number of columns.
  4. Adjust barcode height, width and spacing to suit your labels or paper.
  5. Select Generate barcodes, review the preview, then print or save the sheet as a PDF.

Useful for accession numbers and library labels

Sequential barcodes are useful when processing a new batch of books or preparing identification labels for a collection. The generator creates the barcodes in your browser; your entered values are not uploaded to a server.

Frequently asked questions

Can I keep leading zeros in my barcode numbers?

Yes. Enter the same number of digits in the starting and ending fields. For example, use 000001 and 000100 to keep six-digit values throughout the sequence.

How many barcodes can I generate at once?

You can generate up to 500 barcodes in one batch. For larger collections, create multiple batches.

Can I print the barcode sheet?

Yes. Generate the sheet and use Print or save as PDF. The layout is designed for A4 portrait paper; check a sample with your barcode scanner before printing a large batch.
