# Library Toolkit

Free, practical browser-based utilities for librarians, library assistants and library students.

## Goals
- Free to use, no account required
- Privacy-first local processing wherever possible
- Print-ready outputs with configurable dimensions
- Useful to librarians worldwide, including small school and college libraries

## Planned categories
- Barcode tools: continuous, custom, CSV, member and ISBN workflows
- Label tools: spine, four-line, book, shelf and custom labels
- Library utilities: accession registers, purchase lists, stock verification and calculators
- Data utilities: CSV viewing, cleaning, mapping, formatting and PDF export

The responsive homepage and tool directory list 42 utilities, with 28 available tools. The latest additions cover barcode sheets, CSV-based labels, accession labels, a DDC spine label helper, and CSV and text cleanup workflows.

## Development
Requires Node.js 20+ and npm.
```bash
npm install
npm run dev
npm run build
npm test
```

## Privacy
The project is designed to process uploaded records locally in the browser. Do not add server uploads or third-party processing without documenting it and obtaining user consent.
